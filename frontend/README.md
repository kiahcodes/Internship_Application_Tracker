# Campus2Career – frontend

React 19 + Vite app for finding internships, tracking applications, managing resumes and preparing for interviews.

```bash
npm install
npm run dev      # dev server; /api is proxied to http://localhost:5000
npm run build    # production build in dist/
npm run lint
```

Styling is plain CSS built on the design tokens in `src/index.css`; shared UI primitives live in `src/components/ui.jsx`.
